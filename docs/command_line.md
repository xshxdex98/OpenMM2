# Command-line options

Extracted by `tools/argflags.py` from the calls themselves - each is a string
literal pushed immediately before a `datArgParser` call. This is what the binary
parses, not what any readme claims.

| `-car` | Get(name, i, char**) |
| `-checkalloc` | Exists(name) |

| `-level` | Get(name, i, char**) |
| `-nan` | Exists(name) |
